# Gestor de tareas y ciclos académicos (CLI en Python)

Proyecto colaborativo desarrollado para la asignatura **Mantenimiento de Software (Unidad 2)** del programa de **Ingeniería de Software** de la **Corporación Universitaria Iberoamericana**.

---

## Descripción

Herramienta de línea de comandos (CLI) desarrollada en Python para la planificación, organización y seguimiento de tareas académicas. Permite gestionar ciclos académicos, sprints, estados, prioridades y entregables universitarios mediante una interfaz sencilla basada en consola.

---

## Características

- Gestión de tareas académicas.
- Creación y administración de ciclos académicos.
- Organización de actividades por sprints.
- Clasificación de tareas por prioridad.
- Seguimiento del estado de las tareas.
- Interfaz de línea de comandos (CLI).
- Implementación sin dependencias externas.

---

## Requisitos

- Python 3.8 o superior.
- No requiere librerías externas.

---

## Ejecución

```bash
python main.py
```
